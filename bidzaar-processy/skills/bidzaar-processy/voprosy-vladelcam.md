## Системные наблюдения — не вопросы, а предложения

Три вещи, которые стоит починить не по одному процессу, а разом. Они дешевле любого
отдельного вопроса выше и закрывают половину из них.

**0. Переносить регламенты в базу знаний, а не хранить .docx.** Разбор двух источников
дал неожиданно чёткий вывод: **все проблемы с датами и владельцами есть только у
документов, живущих файлами.** В iSpring у каждой статьи автор и дата обновления
проставляются сами, а для «Регламента закупок» описан полноценный процесс актуализации
с владельцем и сроками — единственный такой процесс в компании. Дальше — распространить
его на все регламенты и перенести туда содержимое папки.

**1. Шапка документа.** Ввести обязательную шапку для всех регламентов — как в
регламенте раскрытия информации CSM (единственном, где она есть):

| Параметр | Значение |

| Статус документа | |

| Применяется для | |
