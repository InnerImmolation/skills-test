# Глоссарий внутреннего языка

Термины и сокращения, которые встречаются в регламентах без расшифровки. Собраны из
контекста документов; там, где значение выведено, а не задано, стоит пометка.

> **В базе знаний есть «Словарь Бидзааровца»** — пространство «1.4 Сотруднику»,
> около 21 000 знаков. Термины ниже, помеченные *(словарь)*, взяты оттуда дословно.
> При расхождении верить словарю: он обновляется, а этот файл собран по документам.

## Процессы и события

| Термин | Что значит |
|---|---|
| **Активация** | Достижение заказчиком уровня по количеству процедур с комиссией + подписанный и оплаченный договор. Срок — 6 месяцев |
| **Забидзаривание** | Этап сделки в воронке CSM, на который переводится заказчик при передаче из Sales |
| **Переактивация** | Повторная активация заказчика из специального списка. В CSM передаётся только после 2 уровня |
| **Отложенный спрос** | Состояние заказчика, снятого с активации. CSM открепляется, Sales забирает права на ЭТП и переносит контакты в AMO |
| **ИПТ** | Индивидуальная поддержка тендеров. Аутсорсинг закупочной функции: тендерный менеджер ведёт закупку заказчика. Бывает полное и частичное |
| **НВИ** | Непрофильные активы / неликвидное имущество. Направление продаж: реализация имущества через тендеры на площадке |
| **ПКО** | Предварительный квалификационный отбор. Сбор квалификационной информации о поставщиках, без выбора победителя |
| **Мониторинг рынка** | Тип запроса для сбора рыночных цен без выбора победителя. Триггер — «Мониторинг рынка» или «RFI» |
| **Переторжка** | Повторный этап приёма предложений после первого круга — для улучшения условий |
| **QBR** | Quarterly Business Review. Квартальный разбор результатов с заказчиком |
| **Питчинг** | Внутренняя процедура вынесения запроса на доработку продукта |

## Типы торгов

| Термин | Что значит |
|---|---|
| **Торги заданного объёма** | Выбор поставщика за известный объём. Вся потребность указывается в столбце «Количество» |

## Метрики и внутренние показатели

| Термин | Что значит |
|---|---|
| **GMV** | Gross Merchandise Value. Оборот закупок, проведённых заказчиком через площадку |
| **КТС** | 🔒 *(словарь)* Числовые значения, используемые для расчёта комиссии: умножаются на стандартную ставку. Система автоматически определяет, к каким запросам применить КТС. Строго внутреннее — красная зона |
| **Кластер** | Внутренняя группировка заказчиков для сопоставления с бенчмарком |
| **Анлим** | *(словарь)* Пакетный / полный / анлим на закупки — специальные условия работы заказчика: участие поставщиков бесплатно, стоимость лицензии рассчитывается индивидуально по потенциалу |
| **Незавершенка** | *(словарь)* Запросы в статусе «Подведение итогов» более 14 дней |
| **Внутренняя градация клиентов** | 🔒 VIP, Бизнес, Комфорт, Стартрек, Альфа. Красная зона: заказчику не сообщается, к какой группе он относится. **Важно:** «Стартрек», «Бизнес», «Альфа», «Вип» — это одновременно и названия отделов CSM, которые ведут соответствующие портфели (см. `references/departamenty-i-otdely.md`) |
| **Процент успеха** | Доля процедур, завершённых с выбором победителя. Порог для передачи в CSM — 40% |
| **Уровень активации** | 1, 2 или 3 — по количеству завершённых процедур с комиссией, зависит от сегмента заказчика по обороту |
| **ТОП-61** | Целевая группа крупных компаний. Упоминается в регламенте СРО-Клуба как критерий признания новым участником |

## Сообщества — три разных, не путать

Разбор словаря снял путаницу, которая была в скилле:

| Сообщество | Для кого |
|---|---|
| **Бидклуб** | Профессиональное сообщество для **менеджеров** по закупкам |
| **Клуб закупщиков** = **CPO клуб** = **СРО-клуб** | Закрытое сообщество **директоров** по закупкам, где они обмениваются опытом, рекомендациями поставщиков и практиками |

Отсюда и разные регламенты: «БИДКЛУБ» — про менеджеров с порогами перфоманса,
«СРО-Клуб» — про директоров с договором-офертой. См.
`references/imidzh-i-soobshchestva.md`.

## ⛔ Термины без расшифровки

Не нашлись ни в документах, ни в «Словаре Бидзааровца» — требуют подтверждения
(вопрос №16 в `voprosy-vladelcam.md`):

**МВК** · **ИДО** (критерий обработки контрагентов службой безопасности в SRM) ·
**ЕДТ** (используется ежедневно в МКК и ТЦ, но нигде не расшифровано) ·
ключи заказчика **«Без поддержки»** и **«Поддержка по запросу»** — механика присвоения
не описана (для «Анлим» определение есть, механика присвоения — нет).
